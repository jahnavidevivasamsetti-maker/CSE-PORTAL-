CSE Digital Hub - Setup Guide

1. Run the site

  1. Open the cse site folder in VS Code.
  2. Set the admin password in the environment before starting the server. In PowerShell, enter it without saving it in a script or source file: 
    $secure = Read-Host "Admin password" -AsSecureString
$ptr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure)
try {
  $env:CSE_HUB_ADMIN_PASSWORD = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($ptr)
  python server.py
} finally {
  [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($ptr)
  Remove-Item Env:CSE_HUB_ADMIN_PASSWORD -ErrorAction SilentlyContinue
}
  3. Open http://localhost:8000 in a browser. The server creates the SQLite database at data/cse_hub.sqlite3.

2. Site features

The portal uses a Python and SQLite backend for CSE projects, hackathon stories, and problem statements. Project submissions must include a project URL, and both projects and hackathon experiences stay private until an administrator signs in at http://localhost:8000/#admin and approves them. Only approved projects and hackathon experiences appear on public pages. Rejected and pending submissions remain hidden from visitors.

The admin password is read from CSE_HUB_ADMIN_PASSWORD; if it is not configured, admin sign-in and review are unavailable. Admin sessions expire after eight hours and are cleared when the server restarts. Use HTTPS and a production-grade server and hosting setup for deployment; do not expose the development server directly to the public internet.

3. Department content

  • The Faculty Directory currently uses the name and designation roster supplied for this project. Confirm the roster is current before production; the supplied information does not include qualifications, contact details, subjects, photographs, or other profile details.
  • Keep faculty directory information, club information, hackathon experiences, and problem statements accurate and verified.
  • Protect personal information and obtain appropriate consent before publishing student photos or private data.

4. Deployment

  • Deploy the Python application and its SQLite database to a host that supports persistent application servers, configure CSE_HUB_ADMIN_PASSWORD as a private environment secret, and serve the site over HTTPS. A static-only host cannot accept shared submissions.
  • Ensure all public routes resolve correctly and file paths remain relative.
  • Include the five root-level logo files (college-logo.png, masters-club-logo.jpg, ar-vr-club-logo.jpeg, rotaract-club-logo.jpeg, and pragsoft-club-logo.jpeg) in the Netlify publish folder when deploying.
  • Test the public pages at desktop and mobile sizes before publishing.
